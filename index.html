cohort.reviews

Cohort is a review platform.

Members write reviews, read them in full, and reply directly to their authors.

entries

No length limit. No format limit.

Text, photos, video. Written once, or extended later — an entry keeps its history rather than resetting.

A single object can carry more than one independent entry.

interaction

Replies are attached to the entry, not to a separate thread.

Any member can reply to an entry. The author can reply back.

entry — running shoes, size 49.5, 8 months "Sole held up fine, toe box felt tight from day one."

reply "Same size — did you size up, or return them?"

reply from author "Sized up half a size. Still using them, 3 months on."
granularity

An entry can target a business, or a specific person within it.

The two are recorded separately.

membership

€2/month.

Required to write, to read entries in full, and to reply. No advertising.
